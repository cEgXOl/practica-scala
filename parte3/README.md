## Parte 3.1 — Visual Studio Code + Metals + sbt

### Mini proyecto: Torneo de Twenty-One

El programa permite:

- Mostrar la puntuación de cada jugador.
- Determinar si una mano es válida o no.
- Calcular el número de manos válidas.
- Calcular el número de jugadores que se han pasado de 21.
- Obtener la mejor puntuación válida.
- Analizar una segunda ronda.
- Comparar los resultados de ambas rondas.

➡️ [Ver Parte 3.1 — Torneo de Twenty-One](parte3-1-vscode/README.md)


## Parte 3.2 — IntelliJ IDEA + sbt

### Mini proyecto: Analizador de calificaciones

El programa permite:

- Mostrar las notas de los estudiantes.
- Determinar si cada estudiante aprueba o suspende.
- Clasificar las notas.
- Calcular el número de aprobados y suspensos.
- Obtener la nota más alta.
- Analizar una segunda evaluación.
- Comparar los resultados entre ambas evaluaciones.
